# Revision 02 · 页面与状态覆盖

以提供的源码路由和组件结构为基线，未新增或替换业务路由。

## 全部现有路由

| 业务路由 | 现有页面 | 每套静态入口 | 真实主题处理 |
| --- | --- | --- | --- |
| `/login` | `LoginView.vue` | `login.html` | 三种新视觉、响应式登录故事区；原有鉴权逻辑不变 |
| `/` | `ProjectList.vue` / `ProjectBrowser.vue` | `projects.html` | 卡片、网格、表单、导航及状态色 |
| `/project/:id` | `ProjectWorkspace.vue` | `workspace.html` | 会话、输入区、工具状态、面板和导航 |
| `/project/:id/branches` | `BranchManagement.vue` | `branches.html` | 分支、工作树、相关弹窗 |
| `/guide` | `UserGuide.vue` | `guide.html` | 阅读宽度、字体、卡片、代码块 |
| `/settings` | `GeneralSettings.vue` | `settings.html` | 现有设置保持完整；顶部新增 Theme Studio 入口 |

同一工作区路由里的终端、文件和 Git 差异，额外拆成 `terminal.html`、`files.html`、`changes.html` 以便独立验收。`components.html` 是状态与弹窗目录。因此是 4 × 10 = 40 个静态视图，不把别名页面计入数量。

## 设置分区

原型包含：界面与主题、项目与工作区、终端、会话、安全与访问、开发者、Git、工作树、数据维护、设置备份。真实应用没有删减任何现有设置项；原型为各分区提供代表性控件，并不声称模拟所有高级设置的后端行为。

## 每套 28 种弹窗／状态

创建项目、编辑项目、目录选择、项目信任、创建工作树、历史会话、会话预览、全局记事本、待审批请求、审批记录、附件预览、命令执行详情、导入会话、本地文件预览、编辑消息、定时发送、技能目录、会话树、移动端会话抽屉、每日提示、文件传输、通知中心、文件预览、导入主题、空状态、加载状态、错误与重试、快捷导航。

机器可读路由映射见 `ui-prototypes/coverage.json`；组件对应文件名在原型的“组件与状态”页显示。

## 保留的业务边界

不修改服务端 API、数据库、会话调度、终端进程、认证守卫、工作树管理和 Git 操作。真实业务仍由原来的组件执行。新增快捷导航只跳转已有路由，不声称执行 agent 命令。

主题变化不通过 theme-key 重建路由视图。原有终端 `TerminalViewport.vue` 的主题 watcher 更新现有 xterm 实例选项。这个生命周期设计经过源码检查；当前环境未完成连接真实后端的持续会话端到端测试。


## Revision 02 工作区契约

四套静态方案固定为左项目、中主工作区、右会话，包含会话／终端／文件／变更四个视图。1440 和 1024 像素下检查三个区域的实际矩形顺序、宽度与右边界；390 像素下左右列表改为抽屉入口，检查 Escape 和焦点恢复。

真实 ProjectWorkspace 的项目侧栏和主区域顺序未调整。WebSessionPanel 的右侧会话栏未移动；原工作树面板和非会话业务面板的可见性不变。主题不会改写原分栏尺寸状态。不同的全局导航仅用于项目总览、分支、设置与指南等非工作区页面。

新增静态总览页测试及终端前景对比度检查。静态覆盖不等于真实鉴权、网络、会话续传或 Git 业务已经端到端验证。
